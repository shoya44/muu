# muu 製品仕様

更新：2026-09-26。要望整理の会話（初回）で合意した内容を反映。「仮決定」はベンダ提案であり、実装前に個別確認する。

## 1. 目的と範囲

- Cloudflare R2 に置いた MP3 を、URL を知る友人同士が iPhone / Android のホーム画面 PWA から聴く。
- 参照・再生・端末保存は誰でも可。アップロード・削除はパスワード必須。
- 起動の速さ、迷わない片手操作、再生継続、最小構成を優先する。
- otoport（PC 原本型）を参考にするが、原本は R2、端末内構造はほぼ同じ。

## 2. 初版で提供するもの

- 楽曲一覧（Home）、ソート巡回、一括保存トグル、曲単位の保存 / 解除。
- 再生、一時停止、前 / 次、シーク、シャッフル、リピート（全曲）、次に再生、キューの並べ替え。
- 歌詞（0.4.0）：曲ごとのプレーンテキスト。再生画面のカバーをタップすると同じ枠に出る。管理者が設定画面で登録する。
- ミニプレイヤー（floating）と再生画面（カバー・操作・キュー）。
- My Playlist：端末内プレイリスト、任意順、Home からの追加（単曲は `…`、複数は行の長押しで選択）。
- 設定：パスワード、既定の保存動作、起動時の復元、ストレージ使用量ゲージと個別解除、更新確認、アップロード、バージョン。
- オフライン再生、バックグラウンド再生、ロック画面 / コントロールセンター操作。
- 起動時のアプリ更新確認（トースト）、一覧の差分同期。
- 前回の曲・位置・キュー・設定の端末内復元。起動時は一時停止。

初版対象外：いいね、プレイリストの端末間共有（JSON エクスポート / インポートは検討枝）、プレイリストのフォルダ、Home の階層表示、履歴画面、再生位置の同期、イコライザー、歌詞の同期表示、ギャップレス再生保証、曲ごとのカバー。

## 3. データの置き場所

### R2（共有・正）

```text
<folder>/<file>.mp3     音声。key がそのまま楽曲 ID
<folder>/<file>.txt     同名の曲の歌詞（任意、UTF-8 のプレーンテキスト）
<folder>/cover.jpg      フォルダ共通カバー（任意）
```

- フォルダは 1 階層。カバーはフォルダ単位で一律。無ければ代替画像。
- 楽曲属性（表示名、秒数、サイズ）はアップロード時にオブジェクトの customMetadata へ書く。DB は持たない。
- R2 に無い曲は Home に出ない。壊れた曲（メタデータ欠落、0 バイト）も出さない。整合性チェックは「R2 に有る＝表示」の一点に集約する。
- 歌詞は曲の付随物。曲を消せば一緒に消える。曲の無い .txt は一覧に影響しない。
- 曲名の変更・フォルダの移動は key が変わる。新しい曲の customMetadata `previous` に元の key を残し、各端末は一覧を取り直したときに保存（音声・歌詞）、プレイリスト、キューを新しい key へ付け替える。正は R2 のまま。

### 端末（個人）

- IndexedDB：前回一覧、My Playlist、再生状態、設定。保存済みの索引は音声の Cache そのもの。
- Cache Storage：アプリ本体、音声、カバー、歌詞を別名前空間で保存。歌詞は曲の保存時に一緒に取り、曲の解除で一緒に消す。
- 端末保存が OS に消された場合は未保存へ戻し、再保存できる。永久保持は保証しない。

## 4. 画面

### 共通

- 3 タブの Navigation Bar：All Songs / Playlists / Settings。アイコンのみ。選択中はアイコン背景の塗りだけで示し、ラベルは出さない。
- Navigation Bar の直上に floating ミニプレイヤー。曲名、前、再生 / 一時停止、次、下端に操作できる細いシークバー。カバーは置かない。曲名タップまたは上スワイプで再生画面。 左右にスワイプで曲送り（左で次、右で前）。曲名が指に付いて動く。
- 楽曲カード（1 行）：`曲名 / 長さ · フォルダ  保存アイコン  …`。行タップで再生。再生中の曲をタップすると一時停止 / 再開（頭出しはしない）。保存アイコンは状態と操作を兼ねる（✓ 保存済み→解除、⤓ 未保存→保存、回転 保存中）。
- `…` はポップオーバー（アンカー付きメニュー）。項目：Play next / Add to playlist / Share / Details / （プレイリスト内のみ）Remove。Share は OS の共有シート（端末に保存済みなら Cache のファイル本体、未保存なら配信 URL）。共有シートが無ければリンクをコピー。共有リンクは無認証の配信 URL そのもので、参照専用。閉じるは外側タップ。
- Android の戻る操作は、いちばん上に開いているもの（ダイアログ、再生画面、プレイリストの中、複数選択）を閉じる。アプリは閉じない。
- タブを切り替えてもスクロール位置を保つ。開いているタブをもう一度押すと先頭へ。
- タップ領域 48dp 以上。長押しは、キューと My Playlist ではドラッグ開始、Home では複数選択の開始。

### All Songs（コード上は home）

```text
[⤨ Shuffle]        [■ ⤓ All] [⇅ New]
曲名A                      3:12   ✓  …
0:12 · Folder
```

- 上段：全曲シャッフル、一括保存トグル（ON = 全曲保存済み。それ以外は OFF で、タップすると未保存分を保存）、ソート巡回ボタン（Folder → New → Old → A-Z → Z-A。標準は Folder）。
- Folder ソートでは R2 と同じ構造でフォルダ見出し（名前、`n tracks / 合計時間`）に区切る。見出しタップで折りたたみ（端末に保存）、右端の ▶ でそのフォルダを頭から再生。折りたたんでもキューと一括保存の対象からは外れない。
- Home の並びはソートのみ。手動順は持たない。
- 空一覧は設定画面のアップロードへ誘導する一文だけ。

### 再生画面

- 上端に閉じる / 保存 / `…`（Add to playlist、Details）。その下にカバー（フォルダ cover.jpg。無ければ同じ大きさのレコード風の代替画像）、曲名、フォルダ名、キュー。下端にシークバーとシャッフル / 前 / 再生 / 次 / リピートを固定。
- カバーをタップすると、同じ枠に歌詞がプレーンテキストで出る。枠の中だけスクロールし、もう一度タップでカバーに戻る。曲が変わればカバーに戻る。歌詞が無い曲では何も起きない。
- 歌詞枠の右下の拡大ボタンで全画面。上に閉じる / 曲名 / フォルダ、真ん中に大きめの本文、下にミニプレイヤー（同じ要素を移して出す。見た目は通常画面と同じ。曲名タップか上スワイプで全画面を閉じ、再生画面へ戻る）。開いている間に曲が変われば新しい歌詞に差し替え、歌詞が無ければ閉じる。
- キューは長押しドラッグで並べ替え、右端の − で除外。現在曲の除外は不可。
- リピートは全曲。キュー末尾で先頭へ戻る（シャッフル中は並べ直す）。OFF なら末尾で停止。
- 上端のつまみを下へ引くと閉じる。キュー途中で下へ引いても閉じない。

### Playlists

- プレイリストカードの一覧。ドラッグで並べ替え。フォルダは持たない（プレイリストと役割が重なるため 0.2.0 で削除）。
- 中身は Home と同じ行。ドラッグで任意順。`…` に Remove が増える。見出しに Play / Shuffle。カードには曲数と合計時間。
- 右下 FAB：Add。Home と同じ行が全画面で並び、右端の印で選ぶ。
- R2 から消えた曲はグレー表示。端末保存があれば再生可。削除時は「この曲は R2 に無く、端末からも消えると復元できない」旨の警告。

### Settings

上に「知っていること」、下に「できること」。

- Storage：使用量ゲージ（保存済み容量 / ブラウザ quota。1 GB 以上は GB 表示）、保存済み曲の個別解除、全解除（確認あり）。
- Playback：既定の保存動作（自動保存 / 手動）、起動時に前回の曲を復元するか。
- Library：パスワード入力、アップロード（フォルダ名 → MP3 複数 → 秒数をブラウザで解析して送信）、削除。曲一覧はフォルダごとの折りたたみ（曲数・容量）。PC ではフォルダごとドロップ、または Folders でフォルダ選択。直下のフォルダ名が R2 のフォルダになり、中の cover.jpg も送る。曲と同名の .txt は歌詞として送る（曲が既に R2 に有っても可。曲が無ければ失敗に数える）。既存の曲は飛ばし、結果はまとめてトースト。曲一覧の各行には Edit ボタンがあり、曲名とフォルダを変えられる（曲名を変えるとファイル名も曲名に合わせる。歌詞の .txt も一緒に改名・移動する。移動先に同名の曲があれば失敗）。同じく Lyrics ボタンがあり、テキストエリアで貼り付けて保存（空で保存すると削除）。Lyrics ボタンで .txt を複数選んで送ることもできる。パスワード未入力ならこれらは出さない。保存済みのパスワードが 401 になったら捨てる（起動のたびに警告しない）。
- Recently played（管理者だけ）：全員の再生を、最後に聴かれた順に 50 曲まで（曲名、どれくらい前、フォルダ）。誰が聴いたかは持たない。開くたびに取り直す。
- App：バージョン、更新確認、更新があればここからも適用。

## 5. 再生とキュー（仮決定）

- 一覧から再生した時点の表示順をキューにする。以後のソート変更はキューに影響しない。
- 「次に再生」は現在曲の直後へ挿入。同じ曲を複数回入れられる。再生中の曲も入れられる（もう一度聴く）。
- キューとプレイリストの並べ替えは、指を離すまで DOM を動かさない。持ち上げた行だけが指に付き、他の行は空く場所へ滑る。離した時点の順序で確定する。
- 「前」は再生 3 秒以降なら曲頭、それ以前なら前の曲。
- シャッフル ON は現在曲をキューの先頭にし、残り全部（再生済みも含む）をランダムに並べる。OFF は元の並びに戻す。どちらも現在曲の再生は途切れない。
- 再生不可の曲はスキップし、理由はトーストで一度だけ。全曲不可なら停止。
- オフラインでは保存済みの曲のみ再生対象。未保存曲は行を淡色にする。
- `<audio>` 1 つで再生。音量はアプリ内に置かない。Media Session API でロック画面・コントロールセンターに曲名・カバー・前 / 次を渡す。秒スキップは登録しない（iOS では前 / 次と排他）。
- iOS 対策：曲の差し替えでは先に一時停止しない（ロック画面・AirPods からの曲送りで無音になるのを避ける）。差し替え中はロック画面を「再生中」のまま保つ。他のアプリなどに割り込まれて止まり、利用者が自分で止めていなければ、割り込みが明けたら続きから再開する（イヤホンを外したときは再開しない）。割り込み後と 60 秒以上止めた後の再開は、今の位置から音声を読み直す。ロック画面には再生位置も渡す。

## 5.1 再生数

- 1 曲を 30 秒、または曲の半分を聴いたら 1 回（短い方）。シークで飛ばした分は聴いた時間に入れない。同じ曲をもう一度頭から聴けばまた 1 回。管理者の再生も数える。
- 端末で数えて端末に貯め、起動時・画面に戻ったとき・通信が戻ったとき・数えた直後にまとめて送る。オフラインで聴いた分も後で届く。
- 出すのは Details だけ。誰でも見られる（権限の区別は無い）。一覧・ソートには出さない。
- 表示はサーバーの合計に、この端末でまだ届いていない回数を足したもの。Details を開くと手元の値ですぐ出し、`/api/stats` を取り直して差し替える。オフラインで一度も取れていなければ `-`。
- Details の項目：Folder / Length / Plays / Rank（再生数の順位、同数は同順位）/ Listened（回数 × 長さの目安）/ Last played（最後に聴かれた時刻）/ Size / Bitrate（サイズと長さから）/ Added（日時）/ Lyrics / Cover / Saved / Cloud / File / Moved from（改名・移動前の key。あるときだけ）。
- 曲の改名・移動では回数も付いて行き、削除では消える。

## 6. 保存

- 音声の保存成功後だけ「保存済み」。カバーは失敗しても取り消さない。
- 1 曲ずつ順に保存。中止後も完了曲は保持。
- 一括保存トグルは「未保存分を保存」。解除は確認を挟む。
- 一覧同期・更新・通信失敗を理由に端末の音声を消さない。

## 7. 認可

- 読み取り（一覧、音声、カバー、アプリ）：認証なし。URL を知る人は誰でも聴ける。
- 書き込み（アップロード、削除）：共有パスワードをヘッダで送る。Worker の Secret と照合。端末は設定画面で入力した値を IndexedDB に保持。
- Cloudflare Access による保護は、パスワード方式で不足が出た場合の代替とする。

## 8. 起動と更新

- 前回一覧を即表示し、裏で R2 の一覧を取り直して差分反映。前回一覧が無い初回のみ「Loading...」。
- 起動時と復帰時に `version.json` を確認する。版が違う、または同じ版でもデプロイ時刻（built）が違えば新版。起動直後で再生中でないとき、または曲を読み込んでいないときだけ、黙って新しい Service Worker を取得し、インストール完了後に切り替えて読み込み直す。それ以外（復帰時に曲がある等）はトースト「Update available」を出すだけで、勝手には読み込み直さない。タップで適用。
- Service Worker の更新で保存音声を消さない。

## 9. 見た目

- Material Design 3 準拠、ダーク固定。Material Symbols（サブセット自前配信）。
- 配色は CSS カスタムプロパティに集約し、`theme.css` だけで差し替えられる。
- パレット（指定）：

| 役割（仮） | Hex |
| --- | --- |
| background | #212129 |
| surface（カード、ミニプレイヤー） | #323949 |
| surface-variant（ポップオーバー、入力欄） | #3d3e51 |
| outline / 区切り | #40445a |
| accent（進捗、選択状態の塗り） | #4c5265 |

- 指定パレットは全て暗色のため、文字・アイコンには白系（on-surface）を使い、accent 上の文字も白にする。accent は「塗り」専用とし、文字色には使わない（コントラスト確保のため）。より明るい accent 系の 1 色が必要になった場合はご相談する。
- Spotify 的な密度：黒地、細い行、カバー主体。強い影・常時アニメーションは避ける。
- 英語の短いラベルのみ。アイコンにはアクセシブルな名前を付ける。

## 10. 成功条件

通信なしで、事前に保存した曲を探し、再生し、画面ロック後も聴き続けられる。再び開いたとき続きから再開できる。友人が同じ URL を開いて同じ一覧を見られる。更新・同期・保存失敗で既存の音声を失わない。
